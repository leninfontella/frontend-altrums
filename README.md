# Frontend Altrums

Projeto web simples desenvolvido com HTML, CSS e JavaScript puro, sem frameworks ou dependências externas.

## Tecnologias

- HTML5
- CSS3
- JavaScript

## Como executar

1. Clone ou baixe este repositório.
2. Abra o arquivo `index.html` diretamente no navegador.

Também é possível utilizar uma extensão de servidor local, como o **Live Server** do Visual Studio Code, para visualizar as alterações automaticamente durante o desenvolvimento.

## Estrutura do projeto

```text
frontend-altrums/
├── index.html
└── README.md
```

## Desenvolvimento

Por ser um projeto feito apenas com tecnologias nativas da web, não é necessário instalar pacotes ou executar comandos de build.
